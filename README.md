# Lazarev Circle

Fan community site for Sergey Lazarev.

Domain: https://independentfancommunityportal.com

## Deploy on your domain

1. Import this repository into Vercel.
2. Build command: `npm run build`
3. Add a Postgres `DATABASE_URL`.
4. Add the domain `independentfancommunityportal.com` in the Vercel project.
5. In Cloudflare, use the DNS records Vercel shows. Set them to DNS only (grey cloud).
